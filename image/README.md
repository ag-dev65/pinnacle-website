# Product image folder

Product images are connected in the `PRODUCTS` array in `../script.js`.

To add or replace the large homepage hero image, place your photo here as `hero-paint-shop.jpg`. The website will show it automatically; otherwise, it keeps the illustrated paint buckets as a fallback. Use a wide, high-resolution JPG, PNG, or WebP image. If you choose a different filename, update the `.hero-feature-image` `src` in `../index.html`.

To add the missing catalogue photos, place image files in this folder using these names:

- `textured-paint.jpg`
- `metal-paint.jpg`
- `waterproof-paint.jpg`

Those cards currently show a placeholder that displays the expected path. After adding each file, refresh the website. To replace any of the existing product photos, either use the filename shown for that product in `script.js` or change its `image` path in the `PRODUCTS` list.

Use JPG, PNG, or WebP image files.
